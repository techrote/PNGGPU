# PNG2ANSI-GPU

GPU-accelerated PNG2ANSI reconstruction research using WebGPU + WGSL.

The original [PNG2ANSI](https://github.com/techrote/PNG2ANSI) project remains the CPU fidelity reference. This repository is for the separate GPU development line, including the GPU-007 tiled renderer, benchmark tooling, and Windows launch scripts.

**Status:** Repository bootstrap in progress. GPU-007 source and benchmark assets are being staged for publication. Do not treat this initial README-only commit as a complete release.

The research renderer is experimental. Exact parity was demonstrated on early photographic fixtures; the extended high-resolution/streaming path is still under hardware qualification.
