What is exact here?

The delivered .ans files contain raw CP437 glyph bytes and ANSI SGR color codes, not UTF-8 text. Rows are inferred from the selected grid. This viewer decodes bytes directly and draws the original exported bitmap atlas. It never asks a terminal font to approximate a glyph and never executes terminal controls.

Checksums are verified against each export’s report.json when available. Downloaded PNGs contain the actual rendered pixels without the difference overlay. MP4 videos use lossy H.264; use this view for exact cell and pixel comparisons. A changed cell is a difference, not a quality score.

Sparse experiment packs work too. Previous/Next steps only through frame numbers shared by all three selected variants.

Local files only · No CUDA work, video seeking or network access · Original ANSI files are never changed
