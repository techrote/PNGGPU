What is exact here?

The delivered .ans files contain raw CP437 glyph bytes and ANSI SGR color codes, not UTF-8 text. Rows are inferred from the selected grid. This viewer decodes bytes directly and draws the original exported bitmap atlas. It never asks a terminal font to approximate a glyph and never executes terminal controls.

Checksums are verified against each export’s report.json when available. Downloaded PNGs contain the actual rendered pixels without the difference overlay. A declared quarter-turn is applied by exact pixel permutation; ANSI downloads keep the original native orientation. Fit mode scales only the display; choose 1× for one rendered pixel per screen CSS pixel. MP4 videos use lossy H.264; use this view for exact cell and pixel comparisons. A changed cell is a difference, not a quality score.

The A/B divider reveals the same image coordinates on both sides. It is not two unrelated half images squeezed together. Drag it or focus the handle and use arrows/Home/End. Incompatible pixel dimensions disable the wipe; incompatible character layouts disable cell differences while aligned pixel differences remain available.

Sparse experiment packs work too. Previous/Next steps only through frame numbers shared by the active comparison: A/B in pair/divider layouts, A/B/C in the other layouts.

Local files only · No CUDA work, video seeking or network access · Original ANSI files are never changed
