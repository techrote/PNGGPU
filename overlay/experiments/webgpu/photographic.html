GPU work-unit research range: safe-integer accounting (no CPU-era GPU work-unit block). Original CPU app retains 125M. GPU limits are up to 1024×1024 cells and 32×64 samples. Very large rasters are streamed in bounded Canvas2D strips rather than allocated as one image; oversized strip resampling is experimental and not yet reference-parity qualified. Tile target is the requested projection-buffer size in binary MiB (1 MiB = 1,048,576 bytes), not a VRAM reservation or guaranteed allocation. Actual tile size is constrained by WebGPU storage binding and raster buffer limits. Depth up to 24 uses independent GPU slots; VRAM calculations automatically update when settings change and must pass the declared-capacity safety gate before starting. GPU shader work remains queue-ordered; more slots only overlap host packing and readback. Preview is suppressed for extremely large outputs, while ANSI remains downloadable. VRAM reserve remains 4 GiB warning / 2 GiB hard block.
